# Alternate, AI-resilient assessment menu

Grounding for the tool's "this item is exposed, here is what to do instead" suggestions. For a flagged item, offer 2 to 3 substitutions **at equivalent cognitive demand**.

## The principle

Authenticity of task does not confer resistance to generative AI. A model will write a portfolio case study, a client rationale, a reflective essay, all authentic tasks. What resists substitution is **process evidence** and **secured evidence**, not a polished artifact. Assess the record of making, not the finished thing.

## The two-lane model (current sector consensus)

- **Lane 1, secured (assessment OF learning):** in-person, supervised, or oral. Validates individual achievement for accreditation. Use where you must prove *this student* can do it.
- **Lane 2, open (assessment FOR/AS learning):** AI use is scaffolded and disclosed; the **process, not the product**, is graded. Use to teach good AI use and judgment.

Five design principles: transparency; validity over detection; process over product; evaluative judgment as a learning goal; program-level coordination (don't fix one assignment in isolation).

## The menu

| Category | What to require | When | Why it resists AI |
|---|---|---|---|
| Process / portfolio evidence | Drafts, thumbnails, version history, working files, commit log, lab notebook, graded | Any make-something course | AI makes a finished thing, not a trail |
| Iterative drafts + named critique | Grade the revision from a specific critique the student received | Studio, writing, peer review | AI can't respond to feedback it never got |
| Oral defense / viva / walkthrough | 3 questions from the student's own claims, with follow-ups; recorded walkthrough of their file | High-stakes summative, capstone | Can't defend unrehearsed decisions live |
| Secured in-class performance (Lane 1) | Move part of the grade to a supervised task | When individual achievement must be validated | Supervision removes the tool |
| Personalized / localized prompt | Anchor to what only this student encountered: a class discussion, a local source they annotated, a place, this week's reading | Essays, research, reflection | Model has no access to situated context |
| Applied project, real client/constraint | A live, local, current problem this term | Case study, capstone, service learning | No published answer to retrieve |
| Reflection tied to a process artifact | "Point to the change between v2 and v3 and explain the critique that caused it" | Replaces free-floating reflection | AI can't point to *your* v2 |
| Applied identification / vocab in use | "Find the hierarchy in a classmate's actual poster and name the element carrying it" | Replaces MC/matching quizzes | Ungoogleable, tied to real class work |
| Disclosure-graded AI use (Lane 2) | Student marks AI vs. own writing and revises the model draft against a named critique; grade the delineation + revision | Composition; any course teaching good AI use | Assesses judgment about AI, the real target |

## Michelle's quick checklist (keep, it works)

Require: a personal/local context; process evidence; response to specific human feedback; a live defense; an artifact with an audience beyond the instructor; something usable after the course. Three-plus yeses = the assessment is doing its job.
