# Instructional-design model lenses

Grounding for the "view findings through a chosen model" checkbox. The findings don't change; the vocabulary and emphasis do. A course does not use every model at once; the lens offers the language the instructor already thinks in.

## The lenses

- **Backward Design / Understanding by Design (Wiggins & McTighe).** Start from desired results → acceptable evidence → learning activities. *This is the tool's native logic.* Lens: does every objective have evidence that assesses it, and does every graded item serve an objective? Flags busywork (activity with no objective) and unassessed claims (objective with no evidence). Strongest lens for the alignment matrix.
- **ADDIE (Analysis, Design, Development, Implementation, Evaluation).** The classic systematic lifecycle. Lens: frame findings as lifecycle gaps, e.g. "strong Development, no Evaluation loop (no self-check, no way to know objectives were met)." Push the workload/seat-time + student-confirmation loop as the Evaluation phase.
- **SAM (Successive Approximation Model).** Agile, iterative alternative to ADDIE: prototype → review → revise. Lens: the whole tool as a SAM iteration engine, "run it, fix the reds, re-export, run again." Good framing for the pilot's rehearse-before-review pitch.
- **Merrill's First Principles.** Learning is promoted when instruction is problem-centered and cycles Activation → Demonstration → Application → Integration. Lens: flag modules that jump to Application with no Demonstration (worked example) or no real problem (Activation), and courses that never ask students to Integrate (transfer to their own work/portfolio).
- **Dick & Carey.** Systems model: objectives, assessment, strategy all mutually aligned. Lens: internal consistency, "component X is out of alignment with component Y" (objective ↔ assessment ↔ activity). Matches the rubric-vs-assignment mismatches the AVC100 report found.
- **Gagne's Nine Events of Instruction.** Nine sequenced events per lesson (gain attention → inform objective → recall prior learning → present content → provide guidance → elicit performance → give feedback → assess → enhance retention/transfer). Lens: a literal per-module checklist. Flag a missing event, no stated objective visible to students, no feedback mechanism, no retention/transfer step. Very tool-friendly.
- **Connectivism / PLEs (Siemens, Downes).** Michelle's theoretical floor: knowledge lives in networks of people and tools; learning is forming and traversing connections. Lens: value external tools, real audiences, community; flag closed-loop courses (no discipline community, no public artifact, no networked tools). Rewards Behance portfolios, Discord critique, real clients, i.e. AVC100's strengths.
- **Bloom's Taxonomy (Anderson & Krathwohl 2001).** See `BLOOMS.md` for the verb bank. The objectives lens: is each objective written at a level a student can be observed performing, and does its assessment demand that level?
