# Universal Design for Learning (CAST UDL 3.0)

Grounding for UDL suggestions. **UDL is not accessibility.** Accessibility = can a student *reach* the content (alt text, headings, contrast). UDL = are there *multiple means* so varied learners can engage, perceive, and express. The tool must say this out loud, because the two are routinely conflated.

CAST released UDL Guidelines 3.0 in July 2024. Goal: learner agency (purposeful/reflective, resourceful/authentic, strategic/action-oriented). 3.0 renames "checkpoints" to "considerations," adds 6 new ones, and foregrounds identity and the removal of biased/exclusionary barriers.

## The three principles

- **Engagement (the "why"):** recruiting interest (choice, relevance, minimize threat), sustaining effort and persistence (salient goals, varied demands, collaboration/community, mastery-oriented feedback), self-regulation (expectations, coping, self-assessment/reflection).
- **Representation (the "what"):** perception (customizable display, alternatives to audio/visual), language and symbols (clarify vocabulary/syntax, decode, multimedia), building knowledge (activate prior knowledge, highlight patterns, guide processing, maximize transfer).
- **Action & Expression (the "how"):** physical action (varied response methods, assistive tech), expression and communication (multiple media and tools, scaffolded practice), executive functions (goal-setting, planning, managing information, monitoring progress).

## Checkable recommendations the tool can flag (distinct from accessibility)

**Representation**
- Content in only one modality (video with no transcript/text, or text-only with no diagram) → recommend a second means.
- Technical terms with no glossary/vocabulary support → recommend one.
- Module with no "activate prior knowledge" opener → recommend one.

**Action & Expression**
- Assignment accepts only one submission format → recommend an alternative means (e.g., a recorded walkthrough *or* a written memo).
- Module with no checklist/planning scaffold → recommend an executive-function scaffold (goal, steps, self-check). Ties to the seat-hours "what this module costs" work.

**Engagement**
- Module with zero learner choice → recommend an option (topic, tool, or artifact).
- No self-assessment/reflection → recommend one (ties to OSCQR 47 and to reflection-based authentic assessment).
- No community/collaboration touchpoint → recommend a discussion or peer critique (ties to RSI).
