Random Tools

A small collection of one-off web tools built to solve a specific problem in my work. None of these are products. Each was born from a real need: a meeting that needed to be scheduled, a form that needed to be sent, a thing that needed to exist for one afternoon. Built fast, mostly with AI as a coding partner.

Built April 2026 · ARC Domain 5

Meeting Scheduler

A scheduling poll built for the District AI Resource Center Student Support & Success Domain kickoff. Google Sheets backend with Apps Script, custom front end in the floral palette. Faculty pick the times that work, the sheet aggregates responses, the chair sees the consensus window. Built in an afternoon when the existing tools were too clunky for what should have been a five-minute task.
