Course Auditor

AI tools & strategy

An AI-assisted tool that reviews a whole online course in one pass, from competency alignment to accessibility, and hands the instructional designer a checkable list of what to fix.

Open the tool

Goal

Catch the alignment, clarity, consistency, and accessibility gaps in a whole course in one pass, so the tedious first review is done in minutes and human judgment goes where it actually matters.

Audience

Instructional designers and faculty getting an online course ready for launch or a quality review.

Process, how it works

Export the Canvas course, then choose what to check: the due-date pattern for any days and time, learning objectives on every project, alignment to the official course competencies pulled live from the Maricopa curriculum site, spelling, directions and accuracy, consistent formatting, and accessibility to ADA Title II and WCAG 2.1 AA. The tool returns a report grouped by category, where each finding shows where it lives, a place to note how you want to change it, and a box to mark it resolved.

Status

An AI-assisted tool, in prototype. It uses no student data and keeps no PII by design. A live version pairs this interface with a parser and an AI model that reads the exported course and generates the findings.
