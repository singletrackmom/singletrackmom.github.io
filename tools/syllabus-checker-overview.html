Syllabus Checker

AI tools & strategy

A submit-and-check tool that verifies a syllabus against the district and program requirements, replies to the faculty member instantly, and logs every submission in one place for the department.

Open the tool

Goal

Make sure every syllabus meets the MCCCD required elements and any program requirements before the term starts, without a person hand-checking each one, and give faculty a clear answer right away.

Audience

Faculty submitting a syllabus, and the department that collects and verifies them.

Process, how it works

The faculty member attaches a PDF or Word syllabus and submits. The submission runs the check against the MCCCD Regulation 3.6 required elements plus any requirements the program has added, then replies right away: a clear sign-off if it is complete, or the exact list of what to add with a button to resubmit. Every submission is logged in a Google Sheet. Program requirements are managed separately by an administrator, so faculty only ever see the form.

Status

An AI-assisted automated workflow, in prototype. It uses no student data and keeps no PII. In production the department form triggers the check, emails the reply, and logs the record in a Google Sheet.
