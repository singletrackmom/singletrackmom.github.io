Service crosswalk
The full grid, every function across all 10 colleges

This is the working spreadsheet behind the inventory: each student-facing function down the side, all 10 Maricopa colleges across the top, and each college’s own local name for that function in the cell. It is a translation layer, not a push to standardize. Every college is independently accredited and keeps its own names; we simply map between them so a persona can be followed from one college to the next. Each college representative confirms and corrects their own column.
