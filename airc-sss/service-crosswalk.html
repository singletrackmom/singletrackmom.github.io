This crosswalk is in progress and is not an authoritative dataset. The first-draft local names were seeded from a public-website review and an agent walkthrough, and each college’s own service owner then confirms and corrects that column. Treat any entry as a starting point until that owner has verified it. The structure is settled. The contents are still being filled in and checked.

1. What the crosswalk is for

Each student-facing function is a row, and each of the ten colleges supplies its own local name. It is a translation layer, not a push to standardize. Every college is independently accredited and keeps its own names. The crosswalk maps between them, so that a persona can be followed from one college to the next and the same task can be attempted at all ten.

The colleges appear in the entries below in a fixed order, in short form: Chandler-Gilbert (CGCC), Estrella Mountain (EMCC), GateWay, Glendale (GCC), Mesa (MCC), Paradise Valley (PVCC), Phoenix, Rio Salado, Scottsdale (SCC), and South Mountain (SMCC). Where a function is identical district-wide, the entry says so rather than repeating the same name ten times.

Two markers carry meaning. “Verify” means a representative should confirm the entry with their own office. “Not found” means no public-facing service could be located, which is a finding to confirm, not an empty cell.

12. How to use and correct this

Working data was assembled from each college’s public website in June 2026. It contains no student data and is for committee use. Each college representative confirms and corrects that college’s entries, and marks “not offered here” wherever it applies, which is a finding rather than a blank. The function list and the surrounding rationale are at map and baseline.
