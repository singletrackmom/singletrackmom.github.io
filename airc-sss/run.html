Your test run

You are one student trying to do one thing. Work it on the real college website from that student’s point of view, out loud, for about fifteen minutes. When something blocks you, that is the finding. You are never told where to go, because a real student is not either.

Before you start

These scenarios follow the student journey, and some need you to already be at a certain point. You cannot pay a bill before you are enrolled. So either use the test account that matches the tier on your scenario, a just-applied account, an enrolled account, or a near-completion account, or, if you are walking one test account all the way through, run the scenarios in the order shown, top to bottom.

If you are only running an AI findability check, just seeing whether the office or the answer can be found online, you do not need an account at all.

Never use a real student’s account or real student data. Only use the provided test accounts. The Needs tag on your scenario tells you which account it takes.

How to run it

  • Give yourself about fifteen minutes, one sitting.
  • Start from the need above and figure it out the way this student would. Do not look up where to go.
  • Narrate as you work: what you expected, what you found, where you got stuck.
  • The moment you hit a wall, dead end, confusing name, form that will not submit, that is a barrier. Note it.
  • Stop at fifteen minutes even if you did not finish. Not finishing is a real result.
