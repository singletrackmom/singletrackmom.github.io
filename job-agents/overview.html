Personal Agents

Personal Agents · Case study

OverviewFind Your FlowFocusSoarNext Steps

A family of scheduled agents, each built for one real reader with one real goal: a job, a gig, a career direction, or a semester abroad. They share one pattern, and that pattern is what students learn to build in the career course.

Goal

Put one concrete, verified next step in front of a person who would otherwise scroll stale job boards or freeze at a giant list of options. Each agent does one job for one reader, on a schedule, so the work comes to them instead of the other way around.

Audience

Each agent serves a single person at a different starting point, which is why they look so different from one another.

Process

Every agent is built from the same five parts, written down in one rules file the agent reads on every run.

PartWhat it decidesExample
GoalWhat the agent is for, and for whomEvery program and award a student can actually use, with the next deadline first (Next Steps)
Where it looksThe organizations and sources it checksEmployers’ own careers pages, never a job board as the final link
RulesWhat counts, what is cut, and how each result is proven realOpen the employer’s page and confirm the posting is live that day
ReportWhat one result looks likeA short card with a why-it-fits note and a direct link
ScheduleHow often it runs, and when it should stopDaily for gigs, weekly for a field that changes slowly, reshaped when the reader’s plans change

Three lessons carried across all of them. Verification matters more than volume: a feed that recommends a job that does not exist is worse than no feed. The schedule has to match the reader’s real timeline, which is why Soar leads with news rather than an empty internship list for eighteen months. And an agent should change with its reader: Find Your Flow helped one reader choose a direction, and now keeps widening her options as she explores further.

In the classroom

The same pattern became the capstone of Design Self Promotion. Students choose a goal type, plan the agent on paper, build and test it in Gemini against its own rules, and put it on a schedule. The Job Search Agent and the Digital Media Jobs board in Render come from the same pattern.

Technology

  • Scheduled AI agents. Each agent runs on a schedule, reads its rules file, searches the web, and verifies every result on the source’s own site before publishing.
  • Static pages. Results publish to a single page rebuilt in place, with no logins and no backend, so the same link always shows the latest run.
  • Verified sources. Employers’ own careers pages for jobs, the U.S. Bureau of Labor Statistics for pay and growth, and local schools for training paths.

Status

Four agents built for four reader goals, all running: all on weekly schedules. The pattern now runs in the career course.
