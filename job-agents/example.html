A fictional animation student’s job search agent, built section by section in full detail, so anyone can copy the method for their own goal.

Why a Fictional Agent

A job search agent works best as a teaching example when every section is visible, so this one is built around Avery Lin, a fictitious graduating animation student looking for a first job in games or animated series, with fictitious studios. It is the worked example students follow in Design Self Promotion.

The Rules File

The whole agent is one document the agent reads on every run. Anything not written down does not happen. These are its sections, in the order they were built.

SectionWhat it decidesAvery’s version
1. Resume firstWhat every result is rated againstRead Avery’s current resume and reel summary before rating anything
2. Goal and audienceWhat the agent is forAnimation jobs Avery can realistically land, ranked honestly, no dead links
3. Must-haves and starsWhat counts, and how well it fitsAnimation is the core of the job; entry level; paid. 5 stars meets every stated minimum, 4 stars has one stretch, 3 or less never shows
4. Top 20 targetsWhere it looks hardestTwenty studios in three tiers: apply and network, apply when it fits, never search (closed or senior-only)
5. BoardsDiscovery, never the final linkArtStation Jobs, LinkedIn, a union board, one regional board
6. TitlesEvery name the job goes byJunior Animator, Associate Animator, Motion Designer, Animation Apprentice, and more
7. Location and rankingThe order results appearHome metro first, then remote, then two cities Avery would move to
8. Cut rulesWhat removes a resultUnpaid, degree with no equivalent, coding as a main duty, heavy travel, below the pay floor, already on the tracker
9. Checking ruleHow a result is proven realOpen the studio’s own careers page and confirm the posting; drop it if it is not there
10. Report formatWhat one result looks likeStars, NEW or CLOSES badge, rank and title, studio, location and pay; then Strong, Light and Lead with
11. TrackerNo repeatsA sheet with Applied and Not applied tabs, read every run
12. ScheduleWhen it runsOnce a month while Avery finishes school, weekly from six weeks before graduation; results rebuild one web page in place, with any 5-star find at the top
13. Change logHow it gets betterEvery correction becomes a dated rule change with the reason

Adapting It

The same thirteen sections work for any goal. A freelance agent swaps studios for clients and agencies; an exploration agent targets organizations in each path being compared; a business agent tracks grants, competitors and suppliers. The rating changes to whatever matters for the goal, and the schedule matches how often the sources change. The full student version, with every step and rubric, is in the course: Avery’s Animation Job Agent.
