OverviewLive toolPRD

A daily agent that finds fresh photo-gig leads and a marketing idea for a working photographer, published to a private board.

Goal

Put a real, apply-today lead near home in front of him each morning, one that fits the work and clears a hard pay floor, so there is always something concrete to act on. Alongside it, offer a realistic move to grow the photography business when wedding work is quiet.

Focus is a daily agent for a working photographer. It surfaces fresh photo-gig leads plus one marketing idea and publishes them to a single private board, refreshed in place every day. It is a personal build: one living page grouped into lanes, not a dated publication, so the same URL always shows the current, verified set of leads.

Audience

One working freelance photographer who needs steady income in the slow stretches between weddings. General job boards are full of stale listings and roles that are not the work he does, so scrolling them is a daily time sink that rarely surfaces a real fit.

Process

A scheduled agent runs each morning to sweep employers’ own careers pages, verify each posting is live that day, and drop anything now closed. Every card carries a short, honest why-it-fits note and a link straight to the real posting. It is a static page with no backend, and anything that cannot be confirmed as a live posting is left off.
