Student Journey Study

Overview · UX Design · AI Tools & Strategy

OverviewPRD

Ten colleges, one student journey, and a severity-ranked account of where it breaks.

Read the study

Goal

Students rarely fail because the help is missing. They fail because they cannot find it, or because the name the college uses is not the word a student would think to type. The goal is to locate exactly where the journey breaks, across ten colleges, and rank the breaks so the fixes happen in the order that matters.

Audience

The advisors and support staff who would use whatever gets built, who are colleagues rather than obstacles, and the district leadership deciding where to spend. The study is written so it reads as taking routine work off staff, because that is what it is for.

Process

A service inventory maps more than fifty student-facing functions across all ten colleges, which is how the naming problem surfaced. Three research personas run against a task taxonomy. Every barrier is scored on a Nielsen severity rating and confirmed by a second rater, so the ranking is not one person’s judgement. The output is a prioritised human-in-the-loop roadmap separating what an agent should answer from what belongs with a person, and a cross-college view showing where one campus already solved what another is still stuck on.

Status

Instruments built and a method pilot of twelve walkthroughs complete, with fieldwork under way. Counts are agent runs; no human participant has taken part in this study. Colleges are reported anonymously.
