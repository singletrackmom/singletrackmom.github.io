Syllabus Checker

PRD · AI Tools & Strategy · Learning Design

OverviewPRD

Checks a finished syllabus against the required elements and reports what is missing.

1. Summary

Checks a finished syllabus against the required elements and reports what is missing.

2. Goal

A syllabus has to carry a set of required elements every term, and the check is done by eye against a list, or not at all.

3. Users and context

Any instructor writing a syllabus, and the program director who reviews it before term.

4. How it works

Rule-based, no AI. The required elements are a published list, so the check is a lookup against that list and the result is the same every run.

5. Data, privacy, and governance

No student data and no personally identifiable information is collected. This is a hard constraint across every tool here, not a feature of one of them.

Status

Built and running as a standalone tool.
