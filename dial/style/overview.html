Style Guide

Course Design · Case study

OverviewPRD

Generates Canvas-safe course HTML from a chosen palette and type scale.

Goal

Course pages drift visually across a program because every page is hand-built and Canvas strips what it does not recognize.

Audience

Faculty building Canvas pages who are not designers and should not have to be.

Process

A palette and a type scale are chosen, and the tool emits HTML that survives the Canvas editor.

Status

Built and in use across course builds.
