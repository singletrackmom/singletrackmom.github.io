Training Plan Agent

Render · Gap to Personal Learning Plan
Prototype · concept demo

Goal, Audience, Process

Goal: Turn the skills gaps a student finds in the real job postings they collect all semester into a concrete, sequenced training plan that closes those gaps.

Audience: Students in the AVC 248 capstone (and any learner using Render), aimed at one real reach job they choose on day one.

Process: The student pastes the requirements from the jobs they saved. The agent compares them to what the student already has, names the gaps, and builds a 90-day plan that maps each gap to a specific, low-cost learning resource. Anonymous by design: no names, no accounts, nothing stored on a server.

This is an early prototype that demonstrates the concept using a built-in skills catalog. In the full Render version this step is powered by the Claude API and draws on the student’s own saved jobs and skills. It is a demo, not a finished tool.
