OverviewLive toolBuild Your Course

The running tool. Upload a Canvas course export and the checks report what to fix.

Open the running toolDial Your CourseDrop in an .imscc course export and choose which checks to run. Nothing is uploaded and nothing is stored.

What comes back

A report of findings, and then the course itself. Tick the changes you approve and the tool rewrites them into the package and repackages the cartridge for reimport. Import it into a sandbox, never a live section. It will not write a package it did not read.

Before you run it

In Canvas: Settings, then Export Course Content, then Course. Studio and YouTube videos export as links, so no video files are involved and the package stays small. A course export contains no student data.
