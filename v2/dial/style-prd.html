1. Summary

Generates Canvas-safe course HTML in a chosen palette, every style inline, because Canvas strips stylesheets.

2. Goal

A course that looks different on every page reads as careless, and Canvas silently deletes any stylesheet attached to a page. This produces headings, callouts, and tables in a consistent palette using only inline styles, which is the only kind Canvas keeps.

3. Users and context

Any instructor building Canvas pages who wants them to look like one course.

4. How it works

Pick a palette, a typeface, and a type scale. The tool emits complete Canvas-safe HTML with every style inline. Twelve palettes, each pre-verified against WCAG AA contrast on every text pair. Five typefaces that render without a web font, since Canvas strips those too. Solid colors only, never gradients.

5. Data, privacy, and governance

No student data and no personally identifiable information. The tool reads course structure and text, never submissions, grades, or rosters. Nothing entered is used to train a model. It is designed to run on district infrastructure with no personal API key in the shipped tool.

6. Status

Built and in use. This tool styles every Canvas page in AVC 183 and AVC 248.
