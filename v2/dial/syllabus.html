What it checks

Checked against the published MCCCD Syllabus Standards, which is a fixed list, so this is a lookup rather than a judgement and needs no AI.
CheckedWhy it fails in practice
Every required standard elementA syllabus rebuilt from last semester carries forward whatever was already missing.
Course and class numbersCombined and associated sections have to list every class, and one is usually dropped.
Seat-hour profileThe profile has to match the course type, and a studio course filed as a lecture sets the wrong workload expectation.
Format and termOnline, hybrid, and in-person carry different required language.
Submission deadlineDue the Friday of the first week, and a program director is otherwise chasing a stack of them by hand.

Faculty write the syllabus in the system the college gives them. What nobody checks is whether the finished thing actually carries every required element. This checks the finished syllabus, names what is missing, and points at the requirement it fails. A captured sample report is the one artifact this page still needs.
