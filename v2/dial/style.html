OverviewPRDDial Your Course

Generates Canvas-safe course HTML in a chosen palette, every style inline, because Canvas strips stylesheets.

Open the running toolStyle GuidePick a palette, a typeface and a scale, and the tool emits Canvas-safe HTML with every style inline. Twelve palettes, each pre-verified against WCAG AA on every text pair.

Goal

A course that looks different on every page reads as careless, and Canvas silently deletes any stylesheet you attach.

Audience

Any instructor building Canvas pages who wants them to look like one course.

Process

Twelve palettes, each pre-verified against WCAG AA contrast on every text pair. Five typefaces that render without a web font. Three type scales. Solid colors only, never gradients.

Status

Built and in use. This is the tool that styles the AVC 248 course pages.
