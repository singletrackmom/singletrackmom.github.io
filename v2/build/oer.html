Reuse unitWhole course, or one simulation dropped into an existing course

The hard part is not finding open material. It is confirming the licence actually permits what you are about to do, and saying so in a form the next person can check. A tool that guesses at a licence is worse than no tool, so the specified behaviour when a licence cannot be confirmed is to report that it could not, never to assume. The course this record describes is Advanced Data Science.
