# STEM Simulation as Assessment, Project Folder

Working home for the STEM simulation-based-assessment portfolio project.

**Start here:** [`stem-simulation-brainstorm-brief.md`](stem-simulation-brainstorm-brief.md) is the canonical hub and the front door, the big idea, brainstorm goals, what makes a convincing problem, candidate topics, and a session agenda. Written so a STEM faculty or engineer collaborator can follow it cold.

## What is in this folder

- `stem-simulation-brainstorm-brief.md`, the canonical brief and brainstorm guide (read this first).
- `mines-flagship-project.md`, the fully worked "Reading the Forces" example (free-body-diagram assessment), used in the brief as one candidate topic.
- `immersive-ai-assessment-plan.md`, the simulation-assessment method, AI role-play, and the XR / WebXR learning plan behind the approach.

Portfolio-wide strategy that mentions this project lives outside this folder in `../portfolio/PORTFOLIO_REDO_PLAN.md`.
