# Wayfinder Project Memory

## The Van
- 2016 Mercedes Sprinter, standard wheelbase (144"), 2WD, not extended
- Approximately 19.5 ft long — fits under all campground vehicle limits (24 ft, etc.)
- Self-contained (no hookups required)
- Has electric fans for heat management

## The Trip
- File: `yosemite-trip-2026.html`
- 15-day road trip, May 26 – June 9, 2026
- Route: Golden, CO → Rabbit Valley → Goblin Valley → Great Basin NP → Lake Tahoe (D.L. Bliss) → Bridgeport → Yosemite (Crane Flat) → Bishop → Valley of Fire → Hurricane, UT → Zion (day) → Bryce Canyon → Salida, CO → Golden
- Travelers: Michelle + teen daughter

## Color System (find-box classes)
- `fb-camp` (forest green) — ALL camping/overnight locations, including backup options
- `fb-night` (purple) — ALL activities: tours, hikes, bouldering, paddleboard, astronomy, programs
- `fb-springs` (copper) — hot springs only
- `fuel-box urgent` (red) — ALL fuel stops, always red
- Default `find-box` (gold) — scenic stops, logistics, tips, route info

## Language Rules
- No time-relative language: no "tonight," "tomorrow," "this morning"
- Use "Day N," "the following day," "Evening ·," "Camp ·" prefixes instead
- No anecdotal asides — formal itinerary tone throughout

## Campsite Vehicle Criteria
- Drive-in access required (no walk-in only)
- Paved or well-graded gravel preferred
- No tent-only sites that exclude vehicle camping
- Driveway grade awareness (standard Sprinter, not 4WD)
