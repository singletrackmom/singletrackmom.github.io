Objectives

Module 2 objectives. By the end of this module, you will be able to:

  1. 2.1 Explain three ways to create typographic hierarchy by setting one line of your own recipe three ways. (Course Competency 2; Understand)
  2. 2.2 Use InDesign to set a recipe on a 12-column grid and to place an outside image at correct effective resolution and color mode. (Course Competency 3; Apply)
  3. 2.3 Apply one hierarchy variable at a time (leading, kerning, weight, case, scale) and explain how each changes what reads first. (Course Competency 2; Apply)
  4. 2.4 Produce an eight-page, print-ready PDF that revises every design, after ranking all eight against the hierarchy goal. (Course Competency 5; Create)

Overview

One recipe, eight designs, a 12-column grid and one typeface. A grid is a set of columns that lines up everything on the page. Hierarchy is the order in which a reader notices things. Each step adds one more hierarchy tool: placement, then weight and case, then scale, then an image. You also learn to place images correctly for print.
