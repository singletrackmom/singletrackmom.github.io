Introduction to Web Design and UX

Courses and Programs · Case study

Course design

A first web design course built for designers. Students take a brand from a style tile to a published, responsive, accessible website for a fictitious client, and test it with real people along the way.

Goal

Teach students to design websites that look right for a brand and work for the people who use them, and to defend every design decision with evidence from usability and accessibility testing.

Audience

A first-year course with no prior web or coding experience required. It serves four programs.

ProgramWhat the course gives them
Graphic DesignAn identity system carried onto responsive layouts, interface components, and accessible color
Digital Media ArtsImagery, video, and motion placed on the web at the right size, with captions
AnimationMotion and illustration used for interface feedback and storytelling, kept accessible
Web Design certificateThe design and UX foundation for the certificate, with a hand-coded path for students who want it

Process

The whole term is one project: a multi-page website for a fictitious client that Gemini role-plays, answering the student’s discovery interview in character. The project moves through five phases, and the final rubric was written first, with one criterion per competency.

WeeksPhaseWhat the student produces
1 to 3Audience researchClient discovery, proto-personas, competitor analysis, customer journey and user flows
4 to 5Planning and structureContent strategy, card sort, sitemap, copy deck, wireframes
6 to 8Visual designMood boards, a brand-to-web style tile, responsive mockups, and the design proposal
9 to 11Interface and interactionComponents with states, an interactive prototype, the first usability test, an accessibility review
12 to 15Build and publishThe full site, a second round of testing, refinement, and a published site with a case study

Backward design set the order: the final website and case study rubric was written first, with one criterion per competency, and every earlier step was placed where it builds a skill that rubric checks. Visual design gets the most weight, because the course serves designers first; usability and accessibility testing come right behind it, so every visual choice can be defended with evidence. Discovery research is a role-played client interview and proto-personas built from public sources; real people take part only in the usability tests.

Outcomes

A student can:

  1. Analyze target audiences, user needs, competitor websites, and website objectives.
  2. Develop website structures using customer journeys, user flows, content strategies, sitemaps, and wireframes.
  3. Produce graphics and visual concepts for web publication using typography, color, and imagery.
  4. Design responsive website interfaces using visual design, navigation, and usability principles.
  5. Evaluate website designs for usability, accessibility, and user experience.
  6. Produce an interactive, multi-page website for publication using contemporary web design and publishing tools.

Pacing and interaction

Two noon deadlines a week, with work posted to the class Discord the day before for critique and a short late window after.

How success is measured

Process work carries ten points per step, and two projects carry the outcome: the website design proposal at midterm and the final website with its case study. The final is defended, so a student must explain the research, the structure and each design decision. Every submission carries a short AI-use log (tool, purpose, what was kept, what was changed), and AI-generated visuals are never accepted as the student’s design.

Access

Designed for learner variability with Universal Design for Learning and built to WCAG 2.1 AA: captioned video, accessible color in every palette, and free alternatives for any tool a student cannot run at home. Accessibility is also course content: every student checks their own site with automated tools, a contrast checker and a screen reader before it is tested with people.

Technology

  • Gemini as the client. Gemini generates the client and the brief, answers interview questions in character, and drafts copy, alt text, and page descriptions the student checks and rewrites. It never designs: logos, layouts, imagery, and interfaces are the student’s own.
  • Design and prototyping. Adobe Illustrator and Photoshop for graphics, Figma for wireframes, components, and the prototype.
  • Publishing. Google Sites with no code by default, Gemini Canvas for an interactive element, and a hand-coded HTML and CSS path on GitHub Pages for students who want it.
  • Testing. Usability sessions over Google Meet, and accessibility checks with WAVE, the WebAIM contrast checker, and a screen reader.

The course is the gateway to UX Design for Interactive Media, and the two share one vocabulary so students never relearn terms.

Status

Offered every spring and fall.
