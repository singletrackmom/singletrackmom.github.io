# Jillian "Jobs You Can Get Now" page, agent rules (flow/jobs.html)

Directions for the jillian-find-your-flow agent when it builds or refreshes flow/jobs.html.
Edit these here in the repo, not in the protected scheduled skill.

## 1. VERIFY-LIVE, every job, every run (HARD RULE)
Before listing ANY job, open the EMPLOYER'S OWN careers site and confirm that role type is
actually posted / actively hiring near Golden that day.
- A web search or aggregator (Indeed, ZipRecruiter, Glassdoor, LinkedIn) is NOT verification.
  Always confirm on the company's own board.
- If you cannot confirm it is live on the employer's own site, do NOT present it as a current
  opening. Either drop it, or list it only as "check their careers page" / "apply in person"
  with no claim of a specific posting.
- Never publish a dead link or an expired posting.

## 2. GET-NOW BAR (who this page is for)
Jillian: 19, high-school diploma, NO degree, NO certificate, ~2 years customer-service/food
experience, lives in Golden. Only list roles that are ALL of:
- Entry-level: no certificate, no license, no prior professional experience required (paid
  training is fine).
- Within ~30 minutes of Golden (Golden, Lakewood, Arvada, Wheat Ridge, west Denver). Farther
  is a stretch, flag or drop it.
- No hard 21+ gate for the core task (she is 19; she CAN serve alcohol, but pure bartender
  roles that require 21 are out).
Anything that requires a certificate (medical assistant, CNA, BLS/CPR), 1+ years experience,
or a degree does NOT belong on this page. Concentra, RESTOR, U.S. Dermatology, Kaiser, UCHealth,
and HCA were removed for exactly this reason.

## 3. LOCATION ACCURACY
List the real nearest store, not a guess. (Trader Joe's has no Lakewood store, use Boulder/Denver.
Tropical Smoothie's nearest is Arvada. Caribou/Smoothie King had no confirmed nearby store.)

## 4. PAGE HYGIENE
- Each section's resume button links the tailored city-only resume in flow/resumes/.
- /flow is noindexed (robots.txt + meta). No forced-download attributes; PDFs open in browser.
- Keep it concise: heading, collapsed cards, one-line note. No walls of text.
