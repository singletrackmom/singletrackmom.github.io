How an assignment is built

From a course competency to a test

  1. Pick one competency. Taken from the official course outline in the Maricopa course bank.
  2. Build the subject-matter expert. An agent cast as a specialist in that field.
  3. Add the instructional designer. A doctoral-level instructional technologist agent that holds the design to authentic assessment.
  4. Write the assignment. An authentic task the student performs with Gemini, with plain instructions a tester can follow.
  5. Run it twice. Once in the under-18 account and once in the 18 and older account, by a synthetic student and by a domain member.
