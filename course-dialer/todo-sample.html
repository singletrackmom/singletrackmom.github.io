Some things a course package cannot carry. This is the checklist the tool hands you after it gives your course back.

Generated from a real run against AVC100 Introduction to Digital Media · 1 credit · 6 actions

An institutional outcome is an account-level object. It lives in Canvas, not in your course, so no export can move it and no import can create it. The tool identifies which outcomes your course already evidences without claiming, names the exact rubric criterion where the evidence is already being collected, and hands you the click path. In the tool these stay ticked when you come back.
1
Attach ILO-VC5 · Analysis: Critique & Interpretation
To the critique criterion on your last graded project of the term.
Canvas → Assignments → that assignment → Rubric → pencil → Find Outcome → Communication Visual → ILO-VC5 → Import → Save
2
Attach ILO-TE1 · Acquiring: Evaluates Creative Process
To the criterion where a learner articulates what they changed after critique, and why.
Canvas → Assignments → that assignment → Rubric → pencil → Find Outcome → Creative Thinking → ILO-TE1 → Import → Save
3
Attach ILO-VC3 · Execution: Technical Skills
To the build step with the fullest toolchain, or the criterion assessing how physical work was captured.
Canvas → Assignments → that assignment → Rubric → pencil → Find Outcome → Communication Visual → ILO-VC3 → Import → Save
4
Attach ILO-VC4 · Delivery: Visual Production
To the criterion where a file is prepared for output: resolution, color mode, bleed, delivery size.
Canvas → Assignments → that assignment → Rubric → pencil → Find Outcome → Communication Visual → ILO-VC4 → Import → Save
5
Attach ILO-W4 · Job Search: Marketing Self to Employers
To the published portfolio, and specifically its written description.
Canvas → Assignments → that assignment → Rubric → pencil → Find Outcome → Career Goals & Workplace Skills → ILO-W4 → Import → Save
6
Attach ILO-TE2 · Risks: Seeks Untested Approaches
Not currently evidenced anywhere in this course. The tool does not invent a home for it. If risk-taking is something the course actually asks for, add a criterion that says so; if it is not, leave it unattached.
Canvas → Assignments → that assignment → Rubric → pencil → Find Outcome → Creative Thinking → ILO-TE2 → Import → Save

Canvas calculates outcome mastery as Highest Score, so one attachment per outcome is enough. Further attachments give the student more attempts at the same figure and clutter the rubric. Scoring is against a graduating student, which means Emerging is the expected rating in an introductory course. Outcome scores are not grades and are not used to evaluate a student or an instructor.
